# Star-Ready Checklist

This checklist is for a responsible public launch. It rejects bought stars,
bots, engagement spam, misleading claims, and surveillance marketing.

## Pre-launch

- [x] README final
- [x] Screenshots present
- [x] GIF present
- [x] CI files present
- [x] Backend tests pass
- [x] Frontend build passes
- [x] Privacy audit passes
- [x] Release verification passes
- [x] No placeholders
- [x] No secrets
- [x] Docker instructions checked
- [x] GitHub topics prepared
- [x] Good first issues prepared
- [x] Release tag prepared
- [ ] Docker build executed locally

## Launch day

- [ ] Create GitHub repo
- [ ] Push main
- [ ] Push tags
- [ ] Confirm README renders
- [ ] Confirm images render
- [ ] Confirm Actions pass
- [ ] Create first release
- [ ] Add topics
- [ ] Add description
- [ ] Open good first issues
- [ ] Share launch posts responsibly

## Post-launch

- [ ] Reply to issues
- [ ] Fix docs bugs fast
- [ ] Label issues
- [ ] Welcome contributors
- [ ] Plan v0.2 publicly
- [ ] Publish v0.1.1 if needed

## Forbidden growth tactics

- No bought stars
- No bots
- No engagement spam
- No misleading claims
- No surveillance marketing

## Current environment note

Docker and GitHub CLI are not available in the current local environment, so the
Docker build and GitHub push must be completed manually on a machine with those
tools installed. The repository files and instructions should still be kept
ready for those steps.
